# 💼 Job Portal - Job Search & Application Platform

This is a frontend-based Job Portal web application that allows users to search for jobs, apply to jobs, and save jobs.  
It uses Firebase for authentication and data handling, providing a smooth and secure user experience.

---

## 🌐 Live Demo

🚀 Visit here:  
👉 https://job-portal-pi-three.vercel.app/

---

## 📌 Project Overview

This Job Portal is a frontend-focused application designed to simulate a real-world job search platform.

Users can:
- Register and login securely using Firebase Authentication
- Browse and search available jobs
- Apply to jobs directly from the platform
- Save jobs for later viewing
